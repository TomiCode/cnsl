# cnsl

A self-hosted server and dashboard for TRMNL e-ink devices: Go backend, Vue 3 dashboard, SQLite,
screens rendered with headless Chrome. Design docs live in a separate repository (`../docs`).

Status: **phase 0** — skeleton (listeners, database, API contract, dashboard shell, Docker).

## Layout

```
cmd/cnsl/              entry point
api/openapi.yaml       dashboard API contract (OpenAPI 3.0) — source of truth
internal/config/       CNSL_* environment config
internal/dashboard/    dashboard API implementation; gen/ is generated by oapi-codegen
internal/firmware/     device listener (firmware endpoints, rendered images)
internal/migrations/   embedded SQL migrations (golang-migrate)
internal/store/        SQLite (modernc, sqlx)
web/                   Vue 3 + Vite + Tailwind dashboard, embedded into the binary
```

## Development

Requirements: Go 1.27+, Node 24+, yarn 1.x.

```bash
cd web && yarn install && yarn build   # once, so the binary has a dashboard to embed
go run ./cmd/cnsl                      # dashboard on :8080, device API on :8081
```

For frontend work run Vite alongside the Go server (it proxies `/api` to `:8080`):

```bash
cd web && yarn dev                     # http://localhost:5173
```

### After changing `api/openapi.yaml`

```bash
go generate ./...                      # Go server stubs + models (internal/dashboard/gen)
cd web && yarn gen:api                 # TypeScript types (web/src/api/schema.d.ts)
```

Generated files are committed.

### Migrations

Add `internal/migrations/NNNN_name.up.sql` and `.down.sql`. They are embedded in the binary and
applied on startup.

## Configuration

| Variable | Default | Purpose |
|---|---|---|
| `CNSL_ADDR` | `:8080` | Dashboard listener |
| `CNSL_DEVICE_ADDR` | `:8081` | Device listener |
| `CNSL_DEVICE_PUBLIC_URL` | — | Device listener URL as devices see it, e.g. `http://192.168.1.10:8081` |
| `CNSL_DASHBOARD_ORIGIN` | — | Origin allowed by CORS on the device listener (virtual device) |
| `CNSL_DATA_DIR` | `./data` | SQLite database and images |
| `CNSL_CHROME_URL` | — | Remote headless Chrome; empty = launch a local one |
| `CNSL_RENDER_BASE_URL` | `http://localhost:<port>` | URL Chrome uses to reach the dashboard listener |
| `CNSL_TIMEZONE` | `TZ`, else `UTC` | Household timezone |
| `CNSL_LOG_LEVEL` | `info` | `debug`, `info`, `warn`, `error` |
| `CNSL_LOG_FORMAT` | `text` | `text` or `json` |

## Docker

Edit the IP addresses in `compose.yml`, then:

```bash
docker compose up -d --build
```
